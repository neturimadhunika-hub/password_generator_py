# Python Password Generator

A simple and user-friendly password generator built using Python and Tkinter. This application generates random passwords using letters, numbers, and special characters.

## Features

* Choose password length
* Generates uppercase and lowercase letters
* Includes numbers
* Includes special characters
* Copy generated password to clipboard
* Simple graphical user interface
* Fast password generation

## Technologies Used

* Python
* Tkinter
* Random module
* String module

## How to Run

### 1. Clone the repository

```bash
git clone https://github.com/your-username/python-password-generator.git
```

### 2. Open the project folder

```bash
cd python-password-generator
```

### 3. Run the program

```bash
python password_generator.py
```

## How It Works

1. Enter the required password length.
2. Click the Generate Password button.
3. The program generates a random password.
4. The generated password is displayed on the screen.
5. Click the Copy Password button to copy it to the clipboard.
